## ⚠️ CSS версионирован

Ссылки на стили несут `?v=N`. **Правишь `tokens.css` или `main.css` — подними номер в `index.html`,** иначе браузер отдаёт закешированную версию. Это уже стоило двух итераций: `299` не менял кегль, хотя токен был на месте.

## Готово

- **Герой** — штамп времени, `299` в Bodoni, ростер реального склада с ценами, полоса с двумя дверьми (поиск + оценка).
- **Секция 2 «Запись»** — инвертированная костяная полоса, 30 000 / $2 млрд / 299 / 4 шоурума, локации.

## Решения, которые не надо переоткрывать

- **Мандат REDESIGN.** Переносятся: рукописный wordmark, чёрный, красный `#CB141D`, статус KARMA, четыре локации, фактура.
- **Три голоса:** Bodoni Moda (display) · Archivo (body) · JetBrains Mono (данные). Раньше было два, display отсутствовал — отсюда была вялость.
- **Красный не десатурируется** — это носитель бренда под REDESIGN. Уступка `color D2` заявлена; рационирование вместо смены оттенка.
- **Две двери равного ранга** — покупка и продажа. Уступка `anti-patterns D6` по условию «genuinely parallel choices».
- **Контраст меряется на композите**, не по токенам. Все замеры проходят AA; `--ink-3` подняли с 0.42 до 0.52 после провала на 3.7:1.

## Открыто

1. **Фотографии нет.** Все кадры — AI-заглушки. Это главный риск: обе записи Semler в vault предупреждают, что крупный масштаб на неровной съёмке усиливает проблему ассетов.
2. **Направление не выбрано.** EXPLORE с тремя вариантами так и не сделан — собирали один вариант и правили по реакции.
3. **Секция 3 — витрина**, крупные кадры 3 в ряд, без кнопок на карточках. Не начата.
4. Данные захардкожены: `299`, ростер, штамп времени. Придут из фида.
